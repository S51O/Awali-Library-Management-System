<h2>Project Overview</h2>

<p>
The Awali Library Management System is designed to make library services easier and more efficient. It allows members to search for books, borrow available books, and return borrowed books while updating book availability. The system helps save time and reduce manual work.

</p>

<h2>Primary Functionality</h2>

<p><strong>UC-3 (Search book):</strong> The member can search for books by entering
keywords such as the title, author, or ISBN in the
search bar.</p>

<p><strong>UC-4 (Borrow book):</strong> The member can borrow an available book by
submitting a borrow request, after which the system
updates the book’s status and records the borrowing
details.</p>

<p><strong>UC-7 (Return Book):</strong> The member can confirm the return of a borrowed
book through the system, marking it as returned
and making it available to others.</p>
